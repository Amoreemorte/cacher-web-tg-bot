# Веб-панель учёта семейных расходов

React + Vite + TypeScript фронтенд для управления семейными расходами.

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Запустить в dev-режиме (проксирует /api на http://127.0.0.1:8080)
npm run dev

# 3. Открыть http://localhost:5173
```

## Требования

- Go-бэкенд запущен на `http://127.0.0.1:8080` (по умолчанию)
- Node.js 18+ и npm 9+

## Конфигурация

Создайте `.env` файл на основе `.env.example`:

```bash
cp .env.example .env
```

Переменные:
- `VITE_API_BASE_URL` — базовый URL API (пусто = same-origin через Vite proxy)
- `VITE_API_PROXY_TARGET` — адрес Go-бэкенда для dev-прокси (по умолчанию `http://127.0.0.1:8080`)

## Сборка для production

```bash
npm run build
```

Результат в `dist/` — статический сайт, готовый к деплою.

## Функциональность

- ✅ Просмотр списка трат с фильтрами (ID, категория, период)
- ✅ Пагинация
- ✅ Создание новой траты
- ✅ Редактирование существующей траты
- ✅ Удаление с подтверждением
- ✅ Адаптивная вёрстка (desktop + mobile)
- ✅ Состояния загрузки, ошибок и пустого списка
- ✅ Без авторизации
- ✅ Без UI-библиотек (чистый CSS)
- ✅ Без сторонних HTTP-клиентов (нативный `fetch`)

## API-контракт

Используется REST API бэкенда:

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/v1/expenses` | Список с фильтрами |
| `POST` | `/api/v1/expenses` | Создание |
| `PUT` | `/api/v1/expenses/{id}` | Обновление |
| `DELETE` | `/api/v1/expenses/{id}` | Удаление |

Фильтры: `user_id`, `category`, `from`, `to`, `limit`, `offset`.

Категории: `еда`, `транспорт`, `жильё`, `развлечения`, `здоровье`, `покупки`, `другое`.
